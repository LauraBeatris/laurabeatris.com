## How a post is organized

Each post is a folder in `content/blog`. The folder name becomes the URL, and `post.mdx` holds the writing:

```txt
content/blog/writing-posts-in-mdx/
├── post.mdx
└── easing-demo.tsx
```

Set the title, description, and date in the `metadata` export at the top of `post.mdx`. Remove `draft: true` when the post is ready to publish.

## Adding a demo

Write a client component next to the post, import it at the top of `post.mdx`, and drop it between paragraphs. Wrap it in `<Demo>` to get the frame:

<Demo>
  <EasingDemo />
</Demo>

Press **Play** and compare how each curve moves the dot. Press it mid-animation and CSS picks up from wherever the dot is.

## Styling

Markdown elements are styled in `mdx-components.tsx`, so [links](/talks), lists, and code all match the rest of the site:

- Internal links stay in the app
- External links open in a new tab
- Tailwind classes work inside demos
